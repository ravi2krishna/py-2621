        -> Logical Operators Are Used For Performing Logical Operations

            -> student enrolled and student attended few classes give course certificate with 4 Stars

    -> Sets 

        -> Set is a data structure which allows you to "store multiple values" 
        in a single Variable, each value is separated with , 

        -> Sets are Represented using {} or "set" class 

        -> Accessing Data In Sets 

            -> Like In Strings, We DON'T Have Index Concept In Sets

            -> Doesn't Support - Index Starts From Zero 

            -> Doesn't Support Both Positive and Negative Indexing 

            -> Doesn't Support Slicing 

            -> Loops We Can Apply 

            -> Operators We Can Apply 

            -> Conditionals We Can Apply 

            -> Duplicates Not Allowed (*)

            -> Insertion Order Is Not Preserved 

            -> Sets Are Mutable

        -> NOTE: To Easily Remember Sets (UUU)

            -> U - Unique Data  

            -> U - Unordered Data 

            -> U - Unindexed Data
