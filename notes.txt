    -> Python 

        -> Python is a high-level, general-purpose programming language 
        that emphasizes code readability, simplicity, and ease-of-writing 
        with the use of significant indentation, an extensive ("batteries-included") 
        standard library, and garbage collection.

        
        -> Python is a High-Level Programming Language 

            -> High-Level Language 

                -> High-Level Language Means "Human Understandable" Language (English)

                -> Python Code Looks Like English

                    num1 = 1.5
                    num2 = 2.5
                    sum = num1 + num2 

            -> Low-Level Language

                -> Low-Level Language Means "Machine Understandable" Language (01010010) 

                -> 01110000 01111001 01110100 01101000 01101111 01101110 -> python


        -> Python is a General-Purpose Programming Language 

            -> General-Purpose Programming Language 

                -> If We Can Build "Multiple Types" Of Applications

                    -> Desktop Applications ? -> Yes

                    -> Web Applications ? -> Yes

                    -> Automation Scripts ? -> Yes

            -> Domain Specific Language 

                -> If We Can Build "Only Specific Type" Of Applications 

                -> Structured Query Language (SQL) is a domain-specific language 
                used to manage "DATA", especially in a relational database management system (RDBMS).

                    -> Desktop Applications ? -> No

                    -> Web Applications ? -> No

                    -> Automation Scripts ? -> No
